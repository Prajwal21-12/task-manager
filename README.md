# TaskFlow — Dynamic Task Manager & Productivity Tracker

TaskFlow is a responsive productivity web application built with HTML, CSS, and vanilla JavaScript. It helps users manage daily tasks, prioritize work, track deadlines, and monitor their progress.

## Features

### Task Management
- Create, view, edit, and delete tasks
- Mark tasks as completed
- Organize tasks into Work, Personal, Study, and Other categories
- Set due dates and identify overdue tasks

### Productivity
- Dashboard with total, active, completed, and overdue task counts
- Completion percentage and progress bar
- High, Medium, and Low priority levels
- Search tasks by title, category, or priority
- Filter by status, category, and priority
- Sort by priority, due date, creation time, and alphabetical order
- Drag-and-drop ordering in Custom order mode

### User Experience
- Light and dark themes
- Theme preference saved in browser storage
- Responsive desktop and mobile layout
- Task entrance animations and completion indicators
- Confirmation before deleting tasks
- Keyboard-accessible controls and reduced-motion support

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## Getting Started

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add tasks and explore the available features.

No package installation, build tools, API keys, or backend are required.

## Project Structure

- `index.html` — application structure and forms
- `style.css` — responsive styling, themes, and animations
- `script.js` — task management, filtering, sorting, and persistence
- `README.md` — project documentation

## Data Storage

Tasks and theme preferences are stored in the browser's localStorage. Data is specific to the browser and device. Clearing browser storage can remove saved tasks.
